IMPORTANT NOTES:
- For amounts, use numbers without currency symbol (e.g. 15000.50 not "15 000,50 EUR"). Use dot as decimal separator.
- secured_principal = the base amount the penalty is calculated from (istina, dlžná suma, cena diela). This is the amount that the percentage rate is applied to. For example, if the penalty is "0,05% denne z ceny diela 500.000 EUR", then secured_principal = 500000. For FIXED penalties (e.g. "zmluvná pokuta 10.000 EUR"), set secured_principal to null because there is no base amount - the penalty IS the amount. Do NOT confuse the penalty amount with the secured principal. Also do NOT use amounts from "úrok z omeškania" clauses as secured_principal for the penalty.
- currency: use the currency from the TEXT, not your assumption. If the text says "Sk" or "SKK", use "SKK". If it says "EUR" or "eur" or "€", use "EUR". Older Slovak decisions (before 2009) often use SKK.
- original_claimed = the TOTAL penalty amount that the plaintiff asked the court to award. This must be an explicit number in the text (e.g. "žalobca požadoval zmluvnú pokutu vo výške 17.010,60 EUR"). If the plaintiff only described a rate and period (e.g. "0,2% denne od... do zaplatenia") without stating the total amount as a single number, set original_claimed to null. Do NOT calculate it yourself.

If the court dismissed entirely, set to null. If the court awarded the full amount, final_awarded = original_claimed. This must also be an explicit number in the text.
