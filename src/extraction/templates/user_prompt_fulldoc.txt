- For amounts, use numbers without currency symbol (e.g. 15000.50 not "15 000,50 EUR"). Use dot as decimal separator.
- In full-document mode, use "full_doc" as chunk_id for all evidence fields.
- Evidence quotes must be EXACT substrings from the text above.

- original_claimed and final_awarded must be explicit TOTAL numbers from the text. If the court moderated (§301), final_awarded must be LESS than original_claimed.
- If there are multiple penalties, create separate entries with penalty_id "pokuta_1", "pokuta_2", etc.
- Distinguish "úrok z omeškania" (interest) from "zmluvná pokuta" (penalty) - they are different!
- secured_principal = the base amount the penalty is calculated from (istina, dlžná suma, cena diela). For FIXED penalties (e.g. "zmluvná pokuta 10.000 EUR"), set secured_principal to null - the penalty IS the amount. Do NOT use amounts from "úrok z omeškania" clauses as secured_principal.
- currency: use the currency from the TEXT. If the text says "Sk" or "SKK", use "SKK" not "EUR". Older decisions (before 2009) use SKK.
- FACTORS sentiment: positive = supports penalty, negative = reason to reduce, not_mentioned = court did not discuss it.
- dismissal_reason is ONLY used when decision.value = "dismissed".
- When decision = "returned" (case sent back for further proceedings), set ALL factors to "not_mentioned" — the court has not analyzed the merits yet.
- DECISION EVIDENCE: For the decision field, cite from the reasoning text where the court explains its decision (e.g. "Súd prvej inštancie žalobu zamietol" or "znížil zmluvnú pokutu na sumu..."), NOT from the verdict section which is one long formal sentence that is hard to quote as an exact substring.
