Your task is to extract structured data about contractual penalties (zmluvná pokuta) from Slovak court decisions.

Create a separate entry in the contractual_penalties array for each DISTINCT penalty that has its own rate definition or secures a different obligation. 9. OUTPUT: Return ONLY valid JSON matching the provided schema. No markdown, no explanation, no comments outside the JSON.
