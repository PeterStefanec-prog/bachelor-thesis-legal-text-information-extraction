IMPORTANT NOTES ON FACTORS:
- "positive" = the factor supports keeping the penalty (court says penalty is fair based on this factor)
- "negative" = the factor argues against the penalty (court uses this as reason to reduce/dismiss)
- "neutral" = court mentioned this factor but did not take a clear stance
- "not_mentioned" = court did not discuss this factor AT ALL. Use this instead of neutral when there is no mention.
- dobre_mravy = rozpor s dobrými mravmi / poctivým obchodným stykom
- zabezpecovacia_funkcia = hodnota a význam zabezpečovanej povinnosti

NOTES ON DECISION:
- awarded_full = court awarded the full penalty amount (no reduction)

- dismissal_reason is ONLY used when decision = dismissed. Otherwise set to null.
